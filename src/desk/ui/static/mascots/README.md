# Desk mascots

Shown only in the Dogs and Cat styles (Plain, the default, shows the Desk ball mark). Never on data, only in empty states, the lesson callout and loading.

| File | Who |
| --- | --- |
| `drew-*.svg` | Drew, a black Scottish Terrier: upright carrot tail, long beard, heavy brow, low fringe, green bandana. James's own dog. |
| `fuzz-*.svg` | Fuzz, a Siberian Husky: tail curled over the back, white mask and chest, blue eye. |
| `soot-*.svg` | Soot, a black cat, sitting. `soot-face-*` is the earlier Desk "Drew" face, which read as a cat, kept as the cat's avatar. |

Each comes in `-light` (for light backgrounds) and `-dark` (outlined, for dark backgrounds); Drew and Fuzz also have `-avatar-` head crops for 24–48 px use.
